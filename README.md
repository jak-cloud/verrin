# Verrin

Marketing website for Verrin — Managed IT services & technology management, Valencia (Europe-wide).

Static multi-page site (HTML/CSS/vanilla JS). No build step. Hosted on GitHub Pages at verrin.cc.

## Pages
- `index.html` — Home
- `managed-it.html` — Managed IT Services
- `solutions.html` — IT Solutions
- `packages.html` — Managed IT Packages (quote-based)
- `about.html` — About Verrin
- `contact.html` — Contact (front-end form, no backend)
